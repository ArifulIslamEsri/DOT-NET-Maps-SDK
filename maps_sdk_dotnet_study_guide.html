🔐 Scope & Accessibility Modifiers (Video 11)

Controls who can see and use a variable or method.

KeywordWho Can Access It?Example Use
publicAnyone, anywhereMap methods the user calls
privateOnly inside the same classInternal helper methods
protectedSame class + child classesBase class shared logic
C# — Accessibility Example
public class MapLoader
{
    public string MapName = "City Map";   // Anyone can read this
    private string apiKey = "abc123";   // Only this class can use this

    public void ShowMapName()
    {
        Console.WriteLine(MapName);   // ✅ Works fine
        Console.WriteLine(apiKey);    // ✅ Works, we're inside the class
    }
}

var loader = new MapLoader();
Console.WriteLine(loader.MapName);  // ✅ public — works!
Console.WriteLine(loader.apiKey);   // ❌ private — ERROR!

📚 Collections — List & Dictionary (Video 12)

Collections are like smarter arrays that can grow and shrink.

📋 List<T>

An ordered list of items. Like an array but you can add/remove items easily. Great for a list of layers or features.

🗂️ Dictionary<K,V>

Stores key → value pairs. Like a real dictionary: look up a word (key) to get its meaning (value). Great for map settings.

C# — List Example
// Create a list of map layer names
List<string> layers = new List<string>();

layers.Add("Streets");
layers.Add("Satellite");
layers.Add("Terrain");

Console.WriteLine(layers[0]);   // Output: Streets
Console.WriteLine(layers.Count);  // Output: 3

layers.Remove("Satellite");       // Remove an item

foreach (var layer in layers)
{
    Console.WriteLine(layer);   // Prints: Streets, Terrain
}
C# — Dictionary Example
// Store map settings as key-value pairs
Dictionary<string, string> settings = new Dictionary<string, string>();

settings["theme"] = "dark";
settings["language"] = "en";

Console.WriteLine(settings["theme"]);     // Output: dark
Console.WriteLine(settings.ContainsKey("language")); // Output: True

🛡️ Exception Handling (Video 13)

Stops your app from crashing when something goes wrong.

C# — try / catch / finally
try
{
    // Code that MIGHT fail goes here
    var map = await LoadMapFromServerAsync();
}
catch (Exception ex)
{
    // If it fails, this runs instead of crashing
    Console.WriteLine("Error: " + ex.Message);
}
finally
{
    // This ALWAYS runs — crash or no crash
    Console.WriteLine("Loading finished.");
}
💡
Think of it like this: try = attempt the task. catch = have a backup plan. finally = cleanup no matter what.

⚡ Asynchronous Programming — async / await

Very important! The Maps SDK uses async everywhere. Without it, your app freezes while loading maps.

🍕
Restaurant Analogy:
❌ Sync = You stand at counter, stare at wall until food is ready. App freezes!
✅ Async = You sit down, relax, waiter calls you when ready. App stays alive!
C# — Sync vs Async
// ❌ BAD — App freezes while loading!
void LoadMap()
{
    var data = GetMapData();   // App freezes here
    MyMapView.Map = data;
}

// ✅ GOOD — App stays responsive!
async void LoadMap()
{
    var data = await GetMapDataAsync(); // Waits without freezing
    MyMapView.Map = data;
}
C# — Real Maps SDK Example
private async void MyMapView_Loaded(object sender, EventArgs e)
{
    // Create map — instant
    var myMap = new Map(BasemapStyle.ArcGISStreets);

    // Load from Esri servers — takes time, but app stays alive!
    await myMap.LoadAsync();

    // Show the map once loaded
    MyMapView.Map = myMap;
}
KeywordMeaning
asyncThis method does background work
awaitWait here, but DON'T freeze the app
TaskA background job with no return value
Task<T>A background job that returns a value

🧩 Object-Oriented Programming (OOP)

OOP is the way C# organizes code. Everything is an object made from a class.

🏠
Analogy: A class is a blueprint for a house. An object is an actual house built from that blueprint. You can build many houses from one blueprint.
C# — Class & Object Example
// CLASS = blueprint
public class MapLayer
{
    public string Name;        // Property
    public bool IsVisible;

    public void Toggle()       // Method
    {
        IsVisible = !IsVisible;
        Console.WriteLine($"{Name} is now {IsVisible}");
    }
}

// OBJECT = actual instance made from the blueprint
MapLayer streets = new MapLayer();
streets.Name = "Streets";
streets.IsVisible = true;
streets.Toggle();  // Output: Streets is now False

MapLayer satellite = new MapLayer();
satellite.Name = "Satellite";
satellite.IsVisible = false;
